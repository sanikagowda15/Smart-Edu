
# Smart Edu

## Personalized Educational Resource Recommendation and Learning Progress Management System

Smart Edu is a web-based educational platform developed using Python and Flask to help students find learning resources, track their progress, and improve their understanding of different subjects.

## Features

- Student registration and login
- Personalized learning resource recommendations
- Learning progress tracking
- AI-assisted question answering
- Image-based question text extraction using OCR
- Smart quizzes and quiz history
- Weak-topic analysis
- Learning analytics

## Technologies Used

- Python
- Flask
- Pandas
- Scikit-learn
- OpenCV
- Tesseract OCR
- HTML, CSS, and JavaScript
- CSV-based data storage

## How to Run

1. Install Python.
2. Install Tesseract OCR if required by the image-question feature.
3. Install the required Python packages:

   `pip install -r requirements.txt`

4. Run the application from the project folder:

   `python app/app.py`

5. Open `http://127.0.0.1:5000` in your browser.
